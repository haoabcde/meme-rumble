# V21 阶梯音量标准

作用于两位角色已登记的素材。用户总音量、音效和角色语音设置继续作用于最终输出。

| 声音层级 | 有效片段RMS目标（dBFS） |
|---|---:|
| 移动、起跳、落地、偷吃等细节 | -32 |
| 普攻挥击 | -29 |
| 普攻命中、格挡、破防、倒地 | -26 |
| 普通技能与技能配音 | -23 |
| 强化技能、神圣命中 | -20 |
| 大招BGM、召唤、主体破水 | -17 |
| 最终巨鲸收尾 | -14 |

每档约+3dB。解码时统计原始PCM峰值，再统计高于峰值8%的有效样本RMS，排除静音填充；同一源素材可按不同用途映射到不同等级。实时增益受最高4倍和单素材-3dBFS峰值限制；极端尖峰素材可能低于RMS目标，优先保留峰值空间。没有改写原音频波形或改变音乐速度。

移除之前普遍0.8/0.85及BGM0.7的任意素材增益，以统一阶梯为基准；水潭实际命中辅助层保留0.5增益，避免和主体破水重复堆叠。总输出新增压缩：threshold -6dB、knee 6dB、ratio 12:1、attack 3ms、release 180ms，主要处理双方、多段和音乐同时叠加的突峰。

测量代表素材，经过校准、用户音量和总线压缩之前，目标-32/-29/-26/-23/-20/-17各档均可达到；巨鲸为-15.59dBFS有效RMS，受-3dBFS峰值限制，仍高于大招主层。原素材试听入口标明不代表实战阶梯混音。

172项检查通过，新增覆盖层级单调、不同幅度素材校准、静音填充不影响、低电平最大增益限制和尖峰保护。战斗判定、BGM生命周期及强化静音规则未改。尚未以真人听感替代这些客观测量。
