# 双角色车轮战

## 进入对战

1. 在模式页把「赛制」切到「双角色车轮战」，选择「本地双人」或「人机对战」。人机模式也由玩家为电脑排出场顺序。
2. 为每队选好「首发」和「后援」。点击对应位置就能改选，也可以调换出场顺序。每队两位角色必须不同，两队之间可以选同一角色。两队都确认后进入选图。
3. 选择场地和交战时限，按「开始对战」。VS 页会显示两队的出场顺序。进场后，双方血条附近用阵容头像区分当前上场、后援待命和已经退场的角色；详细规则保留在本文，减少战斗画面文字。夜训球场的计分牌显示两队剩余角色数。
4. 结算逐段列出对阵和结果。「再战」沿用阵容、地图和时限，重新从双方首发开始。暂停中的「重开本场」也重新从首发开始。「换角色」和「换地图」可以返回相应页面修改。

用键盘选角时，普攻键确认，第一技能键切换首发和后援。人机模式用 P1 的键编辑当前选中的队伍。

同屏仍是每队一位角色，沿用本地双人和人机对战的操作。退场后自动换人，这个赛制没有主动换人或四人同时上场，适用于离线对战。自由训练继续使用单角色。

## 判定与资源

- 每段独立计时，默认 60 秒，可选 30、45、60、90 秒。换人后恢复到所选时限，沿用普通对战的开场准备和暂停规则。
- 单方被 KO 时只淘汰该方的当前角色。时间耗尽时比较当前生命占各自满生命的比例，较低的一方退场。同帧双 KO 或生命比例相等时，双方当前角色都退场。
- 一队两位角色都退场时，另一队获胜。若双方当前角色同时退场，仍有后援的一队获胜。只有两队同时耗尽才判整场平局。
- 留场者继承实际剩余生命、技能能量和自己的眼泪值，后援按该角色的初始资源入场。双方回到各自原来的出生点，防御耐力回满，动作、异常状态、临时强化和按键缓存重置，场上的飞行物、驻留实体、炮台和召唤物全部清空。

## 框架接入

[src/core/relay.ts](../src/core/relay.ts) 用现有的一对一内核逐段运行对局。每段以现有战斗的 KO 或超时判定结束，完成结束演出后才记录该段并推进队列。

- `createRelayMatch(baseConfig, teams)` 接收 `RelayRoster`。数组格式为 `[[P1 首发, P1 后援], [P2 首发, P2 后援]]`，元素是现有的 `FighterDefinition`。
- `stepRelayMatch(session, inputs)` 返回当前交战段产生的 `CombatEvent[]`。换人时 `generation` 递增，`session.config` 和 `session.state` 替换为新的出场配置和状态。AI、HUD 和角色音频通过新的出场配置获取角色定义。
- `indices` 是当前出场位，`eliminated` 是各队退场人数，`history` 记录已完成的对阵和结果。整场结束后从 `session.winner` 读取胜方，其中 `null` 表示整场平局。
- 重开或再战重新调用 `createRelayMatch`。首发、资源、计时、退场计数和交战记录从开场状态初始化。

## 验证

`npm run build` 后可执行 `node --test tests/relay.test.mjs`。回归测试覆盖实际 KO 和双 KO、超时比例规则、替补顺序、资源继承、结束后重开，以及炮台、飞行物、驻留实体、召唤和大招演出的切换。另有标准 1v1 连续平局规则的回归用例。

2026-11-24 验收：构建及全部 246 项测试通过，其中车轮战 9 项。真实 Chromium 浏览器检查了 1440×1000 和 1100×740 两个桌面尺寸的菜单、阵容、地图、战斗 HUD 和结算。

- 本地双人用实际移动与 J 普攻按键，先后 KO 姑姑嘎嘎和香蕉猫，记录 P1 队 2:0 获胜；中途后援满血登场，阵容及资源显示随角色刷新。
- 人机对战跑完三场 KO：大肥鱼击倒电脑首发姑姑嘎嘎；电脑后援香蕉猫击倒大肥鱼，再击倒奶蛙，最终电脑队 0:1 获胜。两次换人时观察到胜者剩余生命 532 和 820 被保留，新登场者为 1000 生命。
- 两场均保持满血到超时，双方首发一起退场、后援登场，最后整场 0:0 平局；逐场记录显示两次超时。
- 暂停时推进 5 秒，HUD 时间保持 24；重开及再战均恢复首发、满血和未出局阵容。电脑阵容调换顺序和五张地图入口可用。浏览器控制台未报告错误。
- 从车轮战切回夜训球场自由训练，仍为单角色、无时限，训练面板可用；再切回标准双人对战，显示第 1 回合和两个胜场标记，没有车轮战阵容残留。
- 按少文字要求精简 UI 后，重新目检了选角、地图和战斗画面，并用实际 J 普攻再次完成首场 KO；头像状态正确切为姑姑嘎嘎出局、香蕉猫在场，HUD 没有重复角色状态文字。

浏览器中的完整计时通过 Playwright 虚拟时钟按正常动画帧推进，攻击和移动使用键盘事件，没有改写生命或战斗状态。本次未进行多人长期平衡验证，也未人工听验全部角色音频素材；音频换库和中断由既有回归测试覆盖。

链接附加 `?format=relay` 可直接打开已选车轮战的模式页，仍由玩家选择本地双人或人机对战；原有训练链接继续优先处理。
