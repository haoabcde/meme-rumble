# 奶蛙步频与普通形态杂纹修正 V27

- 普通移动循环世界步幅由 112 调至 126，步频约降低 11.1%，移动速度不变。支撑脚位移按新的步幅配套计算。
- 普通形态走路、普攻收招、起落和转身的补帧改用连续轮廓包络采样。相邻像素行共用平滑变化的变形场，避免手指、腿部和肚子边缘被逐行拉成细横纹。仍使用原有关键姿势、单张原画纹理和透明轮廓，未使用模糊或双影覆盖。
- 捧腹动作原始第六格左边有一个孤立裁切残片。在裁切范围计算前清理，保留主体附近的半透明边缘。清理函数复用大肥鱼已有逻辑，其效果不变。
- 强化形态、特效、声音、移动参数、攻击与命中时序均未调整。

验证：186 项自动检查通过；奶蛙和大肥鱼各 1600 帧新旧状态对比，战斗、物理和事件一致（忽略纯表现历史字段）。浏览器核对 8 个步态中间帧、5 段普攻各 3 个收招帧、起落及转身帧，并核对正式试玩页普通五段普攻的左右朝向（均实际命中 5 次、158 伤害）。
