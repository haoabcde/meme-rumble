# 大肥鱼 V8：冰蓝水体与银白流光

2026-11-23。本轮按确认的配色方案，仅修改大招演出与水潭特效展示。

- 与龙卷风鲸鱼共享蓝灰、浅蓝、银白的色系；龙卷风鲸鱼沿用原配色函数和绘制参数。
- 大招水鲸从高饱和深蓝改为适度饱和的冰蓝主体，保留较深的背部/腹部转折。按原素材亮度分配色阶，区分青色水体与白色水纹，不把主体均匀提亮。
- 发光提取自变形后的水纹高光，跟随同一身体轮廓，不再把整只放大的鲸鱼重复叠亮；最后巨鲸加强水纹和出水环浪，收住大面积泛白。
- 水潭中心增加透明湖蓝深度，外缘和水纹逐渐转浅；鱼群使用更明亮的浅青蓝/银白，尾迹随原透明度衰减。
- 梁文峰保持居中，演出背景继续深蓝。背后水鲸和鱼群使用相同冰蓝材质，背景能量、雷光、水浪改用统一色阶并降低覆盖强度。
- 保留原像素素材、运动、时停、0.6秒预警、12段/420伤害、1.2秒米饭束缚和全部其他角色规则。没有重绘或覆盖角色母版。
