## 奶蛙规则

- 普通技能一：常态半径240（3身位），三波28/28/44，共100；强化半径336（4.2身位），三波39.2/39.2/61.6，共140。范围和伤害均独立为1.4倍，不再叠乘1.5倍。
- 上＋技能一：仍覆盖整张地图，常态25、强化35伤害，保持无独立冷却。两种技能一均只有强化状态能空中释放；强化空中施法悬停，结束后恢复下落。大招空中释放不变。
- 普攻仍为1.5倍伤害和范围；强化地空移速1.5倍、承伤0.7倍、15秒时长不变。强化冲击环、符文环与命中星芒加重，未恢复技能一已取消的烟花式放射。
- 按住I（技能二/C）在地面保持吐舌比耶蹲姿，松开即时解除。无出招伤害、无能量消耗；保持动作不涨大招能量。
- 实际受到近战或远程实体接触时，免去这次伤害，瞬移到攻击者身后。来源为实体时取发射者位置，不取子弹位置。常态成功触发获得20能量；强化期间继续按剩余时间显示能量，不回填时间条。
- 同一帧多个攻击接触只瞬移一次、只加一次能量；旧位置采集的其余接触一并消费，不让瞬移后继续吃到旧位置伤害或米饭束缚。松开后不再拦截攻击。
- W＋I主动从敌人脚下钻出，无额外伤害、不涨能量。敌人在平台上则落在该平台；敌人空中时选择脚下最近平台/地面。主动版和普通架势均在地面发动。
- 位移瞬间前6个可推进帧暂不暴露受击框，随后恢复；0.3秒动作恢复，无额外冷却。触发后这次架势结束，松开再按可重新准备。
- 地图墙边没有背后空间时选最近可站的另一侧，避免与墙/敌人重叠。普通绕背到空中目标时保留其高度，若脚下无支撑则下落。
- 常态用参考图改绘的淡金旋涡和薄盘，无符文、无羽毛。强化旋涡与法阵更亮，有符文，原地黄白羽毛爆散，目的地增加贯穿地图的垂直圣光。
- 自动接技能一按“开大期间”的上下文处理：仅强化受击绕背，在显现过程后自动接一次强化普通技能一。主动上＋二技能不自动接招；常态受击绕背不自动接招。被打断或强化到期会取消自动接招，避免延迟误触发。
- 强化施法仍保持神圣常态；常态下蹲/钻出使用新像素姿态。新增普通待机的托腮思考、歪头、轻微呼吸，直接移动/出招即可退出。

3. 大招视觉范围与判定区：本轮严格保留水潭12段。冲上高空的鲸鱼不带额外远程判定；这是需要交接清楚的呈现约定。
