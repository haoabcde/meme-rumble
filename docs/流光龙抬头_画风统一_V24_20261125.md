# V24：龙抬头恢复金白流光画风

按用户提供的金白流光参考图，仅替换强化普攻第五段六帧素材。

- 龙形由白色亮芯、金色边缘、尖锐光带与镂空间隙构成，与前四段共用能量特效画风。
- 去掉上一版实体金龙的鳞片、金属体积、厚颈和盘蛇身体。
- 保留六个逐渐抬头姿态。按后续要求加速：每姿态由5个战斗帧改为3帧，抬到顶点约0.25秒，完整效果约0.52秒；峰值略停，尾光迅速收束。根部位置和读取比例一致。
- 前四段特效、判定、攻击距离、伤害、声音和0.466秒偷吃配音沿用V23。
