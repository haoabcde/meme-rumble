# 奶蛙强化五段与大肥鱼配音 V22

本轮按现有角色玩法优化，暂停统一规范 v0.2 迁移。正式游戏和预览共用同一套素材、判定和声音。

## 奶蛙

- 强化普攻在现有横向距离上乘 1.2：常态的 1.5 倍 → 1.8 倍。高度仍是原来的强化高度，伤害仍为常态的 1.5 倍。一技能半径及伤害仍为 1.4 倍。
- 五段改为穿光、双弧、升羽、环震、长虹。以本次两张参考图的火焰弧、翼状能量和长流线为构形，重新绘制成白金像素素材，没有直接裁进原图中的背景、水印或建筑。
- 保持神圣悬浮形态。每段有展开、流线起伏、方向变化及余辉衰减，攻击取消后余辉继续自然消失。左右使用同一局部坐标镜像。
- 新增五种独立挥击声音和一种强化普攻命中声音，不再共用一技能的神圣震波/神圣命中。
- 原有大招 BGM、强化技能一与其声音保持不变。

## 大肥鱼

配音均来自用户提供录音，未使用合成或克隆声音。原文件保留，生产文件为单声道 44.1kHz PCM WAV。切点有极短淡入淡出以防爆音。

| 场景 | 原录音切点（秒） | 声音标识 |
|---|---|---|
| 普攻第一段 欧 | 声音参考 0.835–1.185 | tail-voice-1 |
| 普攻第二段 鲸 | 声音参考 1.185–1.400 | tail-voice-2 |
| 普攻第三段 鲸 | 声音参考 1.400–1.780 | tail-voice-3 |
| 大招演出 鲸鲸 | 声音参考 1.185–1.780 | ultimate-voice |
| 偷吃米饭 两次喃喃 | 吃米饭 1.770–3.440、3.590–5.670，去掉间隔后拼接 | eat-voice |

普攻配音在对应动作开始触发；下一次配音替换上一段配音，避免连击语音叠加。大招配音在时停演出开始触发。偷吃仅在真实抽中偷吃动作时发声，投出米饭不发偷吃语音。

音量沿用阶梯标准：普攻配音 −23dBFS、偷吃 −26dBFS、大招喊声 −14dBFS；强化普攻新音效 −20dBFS。均为活动样本 RMS 目标，仍受峰值限制、用户音量及混音总线控制。没有增加场景环境音。
