# 梗角色大乱斗角色与战斗统一设计规范 v0.1

2026-11-24 · 团队评审稿 · 适用于大肥鱼、奶蛙、香蕉猫、姑姑嘎嘎及之后接入的角色

**普通技能消耗 0 杀气。每个角色默认提供两招大招，第三招按需要审批。所有角色共用核心操作和受击规则，角色负责人决定招式效果、节奏、专属资源和表现。** 主界面由用户负责。本规范涉及选角或暂停页的字段交接，以及战斗 HUD 的状态正确性。

文中的键位、帧数和能量档位是供团队评审和联调的建议。现状与证据见同目录的《死神 VS 火影横纵分析报告》。

## 1. 公共输入语义

物理键可重绑，招式配置只读逻辑输入。P2 现有小键盘别名保留。方向组合以按下动作键时的方向为准，上下与左右同时按时动作仅采用上下修饰，左右继续决定移动或朝向。冲突依照本节统一处理。

| 意图 | P1 默认 | P2 默认 | 公共行为 |
| --- | --- | --- | --- |
| 移动 | A / D | ← / → | 空中可调整水平位置 |
| 防御 | S | ↓ | 地面按住持续防御，耐力按公共规则扣减 |
| 跳、二段跳 | K | 右 Shift／小键盘 2 | 空中二段跳和空冲共享一次机动 |
| 平台下穿 | S + K | ↓ + 右 Shift／小键盘 2 | 只在可下穿平台发动。平地按下时执行普通跳跃 |
| 冲刺 | L | Enter／小键盘 3 | 地面和空中均可按规则冲刺，失败反馈明确 |
| 地面普攻、空中攻击 | J | 逗号／小键盘 1 | 地面首段可达。空中有可用的基本攻击，无专属资源时也能使用 |
| 挑空 | W + J | ↑ + 逗号／小键盘 1 | 地面必有挑空。命中才可按跳跃追击 |
| 进攻技 | U | 句号／小键盘 4 | 地面必有主动进攻，如投射、突进或对空。攻击覆盖可按角色设计 |
| 特色技 | I | 斜杠／小键盘 5 | 地面必有角色机制，例如炮台、蓄泪、架势或空间控制 |
| 终结／特色大招 | O | 单引号／小键盘 6 | 较高资源档。可做终结、变身、召唤或区域控制 |
| 战术大招 | W + O | ↑ + 单引号／小键盘 6 | 较低资源档，解决一个清楚的战术问题 |
| 可选第三大招 | S + O | ↓ + 单引号／小键盘 6 | 只在角色配置已登记时启用，承担与前两招可区分的职责 |

基线仅要求表内必备动作。普通技可申请 W+U、S+U、W+I 或 S+I，优先使用现成、有可解释差异的动作。基础冲刺与下穿的手感独立于角色包。下+J 属可选地面技能，已有泪滑和滑铲可登记。对未登记的方向变招，J/U/I 执行同姿态基础动作。已登记变招因冷却、资源或状态失败时，显示该招失败原因。大招采用严格方向匹配，没配第三招的 S+O 不会误扣终结大招。

### 动作选择与双人输入

- 先按逻辑键、方向、动作时的落脚情况、形态选择唯一候选；明确变招优先于中立槽，同一分支同一个优先级不能有多个可达动作。地空都合适的动作可显式设 `any`，需验证边缘和落地前后。没有空中版本的招式在训练或招式表明示「地面限定」。
- 同一输入只能提交一个动作。满足取消窗口、耐力、专属资源、杀气、实体上限和演出独占后，原子扣费并创建动作。失败无扣费、无实体、无残留输入，也不会自动尝试另一个大招。同帧双方大招须用公开一致的仲裁，比赛中不因 P1 次序获益。
- 特殊组合和电影大招也进入同一候选、校验和提交路径。禁止先由动画或角色状态抢走 O。形态改变应沿用相同语义。支持把初期的旧命令登记为过渡别名，UI 只显示规范键。
- 防御与一个有意图的动作同帧时，若动作合法则退出持续格挡并提交动作；已经处在格挡硬直时只可接登记的防反。两个相反方向互相抵消，始终按物理 `KeyboardEvent.code` 接入可重绑逻辑键。
- 双人规定同键重绑冲突要定位到另一方的具体动作。实机检查机械全键盘、普通笔记本键盘、无小键盘外接键盘。并按 P1 W+O 与 P2 ↓+右 Shift、P1 S+K 与 P2 ↑+逗号；操作有遗漏时给双方可重绑的替代键组。失焦、暂停、读图、设置开关时清掉旧输入。手柄接入可沿用逻辑层，其支持状况按实际验证展示。
- 建议动作缓冲从 **5 个模拟帧**开始，一次消费，受击、回合切换清掉不适用项。严格判定「真连」时同时确认陪练最快防御或跳跃仍无法插入。实测分 3、5、7 帧跑快、慢连段、双人同时输入和失焦，最后选误触率与可复现性合适的一档。

## 2. 普通技能与大招的资源

普通攻击、U、I 和普通方向变招的公共 `energyCost` 恒为 0。普攻、挑空、U、I 都要有明确的使用场合与反制。先用起手和收招限制重复使用，再按招式选 **一类**主约束。投射物用数量及速度、炮台用同主人存续上限或共享冷却、架势用短窗口和失败收招、位移用收招和空中行动预算、专属蓄力技用可见资源与回收机会。

香蕉猫保留眼泪。专属资源要有局内可见读数、回补路径和资源归零后的基本作战能力。大肥鱼投射状态、奶蛙强化计时、炮台存在与冷却同理。防御耐力继续承担格挡和冲刺相关规则，普招不另设第二条共用收费体系。

| 槽位 | 功能 | 杀气建议初值 | 验收 |
| --- | --- | --- | --- |
| O | 终结、强控制、召唤或强化 | 300／3 格 | 读得到起手提示，有明确的回避、挡下、打断或等待时机 |
| W + O | 较短的确反、连段收尾或脱离后重获主动 | 100／1 格 | 可在更早阶段使用，单次收益和覆盖与上面一档有差别 |
| S + O | 可选，补足不同战术需求 | 200／2 格 | 和另外两招分别说明对局中何时选、对手怎么应对，双人键盘可达 |

- 保留三格、每格 100 的视觉主体。成本在统一提交点扣一次，落空照扣，非法输入与演出仲裁失败不扣。评审初版保留现有每回合重置气量的行为。命中和受击的积累需要分别记账。先沿用当前基线做对局，测首次到 1 格和 3 格的分布与攻防双方获得率。
- 多段、实体、连续命中、碰撞暂停和特写不得无上限地反哺气。先以「同一使用实例按攻击实例给固定总气量上限」试做，首版投资大招的效果期间不返还施放者的杀气。每回合主约束按实际机会评估。
- 强化计时使用独立字段，不能回填杀气栏。禁止一边覆盖气、另一边继续按气栏判断可施放。状态结束、角色 KO 和回合重启需清除改写的形态、实体及相关音频。
- 团队评审决定具体资源档、是否留第三招、电影开招打断点，以及防守方连段逃脱是否进入下一版。团队可直接按两招接口准备草案。

## 3. 攻击素材必须交代的判定

一招的最小交付包括其唯一动作 ID、输入、姿态、攻击角色、起手／有效／收招、攻击和受击框、命中反应、格挡反应、命中组、朝向、取消和可中断点。技能的威胁范围以世界坐标描述，射程随镜头变化的表现保持一致。

| 项目 | 要求 |
| --- | --- |
| 起手 | 让对手识别威胁位置或方向，标出能否被打断及何时锁定朝向 |
| 有效 | 每个活动窗口有实际判定，显式登记可打地、空、倒地，以及多段触发帧 |
| 收招 | 明确哪一帧重新行动、格挡、移动或落地，打空仍进入收招 |
| 自身判定 | 受击框和攻击框分开按骨架或关键帧检查。无敌标起止帧和适用情形，霸体标吸收次数或可承受攻击类型，破防及不可防标明专门反制 |
| 启动方向 | 默认在招式提交时记录朝向，镜像只算一次；允许开招期追向时写出锁向帧；飞行物生成后保留独立方向 |
| 多段与实体 | 同一实例、同一目标、同一命中组每组只算一次；周期伤害要声明重击间隔、最大命中数。实体需说明主人、出生、命中穿透、存续、上限、互斥、平台与 KO 清理 |
| 反馈 | 命中与格挡使用可区分的停顿、粒子、动作和声音。强招标明来源、即将覆盖的位置和范围。关闭镜头震动后仍可读，连续命中不覆盖双方本体与落点 |

联调时对每招画出时间条。先跑起手中被打、打空、打中、被挡四个剧本，再跑身后、跳台、台沿、落地和镜像。普通攻击使用短的 hitstop、较强攻击可更明显。数字测试以当前 60 Hz 引擎为准，角色演出帧表和实际判定帧表逐帧核对，禁止仅延长全局停顿制造快感。

### 连段、取消与受击状态

- **常规主线**为前一至两段普攻命中 → W+J 地面挑空 → K 跳消 → J 空追。持续 J 可走角色自己的连击，允许在预声明的接续窗口续段。空挥／格挡可以续公共普攻时，接续仍留出对手行动机会，并单独验证整条串压。跨槽取消默认命中限定，按显式目标、窗口和命中结论许可；电影和持续施法也受同一规则。防守方仍会受到长段连击时，优先缩短、降伤或留断点。
- **hitstop** 只表示命中停顿。**hitstun** 是停顿结束后受击方剩余的不可操作时间。**blockstun** 从格挡成立开始记独立硬直并消耗防御耐力，破防另进入可验证的专属硬直。训练同步展示命中后双方何时恢复，攻击与防御硬直禁止用同一个标签。
- **空中失控** 应显示弹道、落点和当前是否还能被追击。**倒地、起身**分别有独立阶段，默认期间不可重复打伤，起身帧和可格挡帧须统一。起身继续保护时用明显轮廓或闪烁提示，并定义主动出招何时解除保护。
- **防反** 分开定义精准防反、角色架势和受击脱离。公共防御有统一朝向规则、耐力、硬直与破防。大肥鱼保留特色防反，但在招式表和训练显示有效窗口、近远判定、失败结果，持续防御反制若保留要给清楚的破绽。公共精准防反可在基础规则稳定后评审。
- **连段保护** 先提交可复现的连段上限验收，再决定需不需要系统逃脱。对重复浮空、贴墙、双炮台＋本体、召唤＋弹体分别测无资源真连，记录首击至首次可行动时长、伤害和接触次数，排除无限循环。若现有落地保护不足，可先在同一连段累计到指定窗口后强制收尾与起身。受击脱离若进入下一版，独立给按键、一次性成本、可用窗口、失败反馈，并保证双方一致。

## 4. 四个角色的迁移表

状态均为迁移建议。角色名与现有招式沿用角色配置。带新增标记的招式为用途草案，角色负责人决定最终动作和素材。

| 角色 | 公共招 | U 进攻槽 | I 特色槽 | O／W+O |
| --- | --- | --- | --- | --- |
| 大肥鱼 | 保留三段尾击和空中尾击，补独立 W+J 尾巴挑空和跳消 | 米饭投手保留，W+U 保留向上投饭 | 旋风推进与 W+I 定点旋风保留；持续防反按统一窗口评审 | O 保留「开源！」水潭。新增 W+O 快速鱼群确反，短范围、较低收益，与长演出有明确差别 |
| 奶蛙 | 保留五段掌击、踢击与空中踢，补 W+J 蛙腿挑空和跳消 | 捧腹大笑；W+U「响彻天地」核对前方、远距、全场读招和连段 | I 下蹲架势，原方向瞬移保留，触发、落点和失败提示统一 | O 保留「神了！」强化。新增 W+O 短程震波终结，明确强化前后同一输入，并用独立计时 |
| 香蕉猫 | 保留四段连击、W+J 挑空、S+J 泪滑。加跳消与零眼泪空中基础攻击 | 高压眼泪／W+U 哭哭升龙保留专属成本 | 长按 I 哭泣回泪，验证受击、松键或落地后的恢复 | O 保留「泪海滔天」。新增 W+O 短程破绽确反，单独标姿态和资源档 |
| 姑姑嘎嘎 | 保留五段普攻、空投、W+J 冲锋挑击、S+J 滑铲。补命中挑空与跳消 | 新增 U 独立电线杆进攻，优先复用电线杆概念及原创动作能力 | 两种炮台改为零杀气，地空区分、同主人上限和共享冷却 | O 保留「帝江」。新增 W+O 的短程炮击终结，避免和部署炮台互相触发 |

建议第一批只交两招大招。若第三招方案无法说明独特选择时机、预算和对手应对，角色可按两招参加合并验收。

## 5. 接入和验收

### 公共维护者

1. 明确 `defineFighter` 角色包与公共动作的合并优先级，用槽位约束检查必要动作可达，静态检查普通技成本及大招唯一方向。把地空后备、电影分支、召唤和资源失败纳入同一动作仲裁。决定性状态只能从模拟帧输入更新。
2. 锁定当前测试基线，完成伤害、格挡、双方同帧、同一实例多段、姿态切换、取消、资源扣除和回合清理测试。同一初始状态、输入序列和地图运动必须复得相同事件序列与最终状态，模拟不能读真实时钟或渲染偏好。通过 P1/P2 镜像、实体重叠、特写期间输入和帧缓慢测试。
3. 给界面负责人交付招式名、输入、姿态、用途、消耗、失败原因、效果时长、预计算可用条件。三格气槽底部继续服务局内读数。可用大招由合法动作判断，选择页、暂停页、训练和 HUD 使用同一事实。气够但在空中的地面限定大招应有可用条件解释。
4. 训练保留静止、格挡、重复直拳、慢速和单步，优先补「首击后立刻防御／跳跃」「输入是否采样」「当前连段／保护」显示。新手练习依次是移动和挡、J 连击、挑空空追、U/I、两招大招。换角色可用同一讲法完成对应任务。

### 每个角色负责人交付

- [ ] 写一张动作表。每行列 `actionId`、槽位、方向地空、招式用途、显式成本、起手／有效／收招、取消及受击结果，标点注明近地／空中、反制、实体上限和音画文件。
- [ ] 验证两边朝向的地空 J、W+J、U、I、O、W+O，分别从 0／1／2／3 格启动。资源不足、正在硬直、非法姿态时不误选另一招或重复扣费。
- [ ] 对每个常用技能记录一次打空、被挡、命中、遭打断、先手连段以及对手可行动帧。角色特例另交零眼泪、已召唤、强化到期或反击窗口关闭的证明。
- [ ] 检查直播擂台和至少一张多层图，内容包括台沿出招、空中落地、双方换边、同角色镜像、投射与炮台撞边、暂停恢复、KO 与再战清理。
- [ ] 做一次 2P 键盘试验，记录试验设备、组合键和丢键情况。核对 HUD、招式表和训练用词一致。完成关闭震动／仅看画面的命中、格挡和范围提示辨识。
- [ ] 提交角色包改动、动作表、覆盖的测试结果和两段短录屏。第一段给新人看招式输入和用途，第二段给维护者复现最强无气连段及其反制。

### 合并顺序

1. **P0 系统语义与阻断修复**。统一 W+J 和跳消，修复炮台公共成本、嘎嘎 U 缺位、气槽错误就绪、猫空中 J 的资源后备、电影大招输入抢占与奶蛙气量字段冲突。先用一个普通大招和一个电影大招的组合穿通。
2. **P1 四角色迁移**。各自接齐两个用途不同的大招，保留角色机制。验证无气压制、连段逃脱机会、起身、双人键盘和多层图。
3. **P2 基于对局数据的扩充**。只有实测提出现有槽位无法解决的战术问题时再评审第三招。公共精准防反、主动连段逃脱、手柄和更深的平衡迭代按实际需求取舍。

平衡验收先记录首个上手任务完成率、每人第一次到 1 格／3 格用时、最高无气真连伤害和锁定时长、角落与多层图差异、两类大招使用率、命中收益和被确反率。以四人交叉对战、互换 P1/P2、同角色镜像和至少一轮新手换角为基线。样本只用于找问题，后续的强度阈值由对局记录决定。
