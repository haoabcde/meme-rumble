# 四角色画风统一

四位角色使用清晰的卡通手绘美术。重绘保持各自身份、服装、朝向、动作意图和技能设计，原格序、世界尺寸、时序与判定继续沿用。原角色及技能设计由队友负责。[素材目录](../assets/fighters/unified-handdrawn-v1/README.md)

## 素材范围

| 角色 | 当前版本 |
|---|---|
| 大肥鱼 | 79 个有效画格已重绘，保留 80 个槽位。每格使用 432×432 源像素，通过 `art.motionScale: 2` 映射到原 216×216 逻辑格，脚锚仍是 `(108, 184)`。 |
| 奶蛙 | 新目录为 `motion/frog-reference-v2/`。重绘 37 个常态画格，保留用户指定的 2 个侧躺出场画格和 8 个天使画格。变身演出保留左侧天使，右侧普通奶蛙按选定原图修订。 |
| 姑姑嘎嘎 | 重绘 55 个场上关键画格和 4 个帝江演出画格。 |
| 香蕉猫 | 重绘 21 个场上关键画格和 3 个泪海演出画格。 |

奶蛙的 37 个重绘画格包括基础动作 16 格、出场与胜负 6 格、拳脚及技能 8 格、普通移动 4 格，以及护腹防御、下蹲、思考各 1 格。保留的侧躺姿态位于 `scenes.png` 第 0、1 格。`angels.png` 全图和 `travel.png` 强化移动所在的下半部沿用原像素。护腹防御保持原姿势，眼神朝向玩家是本版验收项。[最终选图](../assets/fighters/unified-handdrawn-v1/frog-reference.png) · [奶蛙素材目录](../assets/fighters/unified-handdrawn-v1/motion/frog-reference-v2/)

## 使用与验收

- 奶蛙的立绘与动作比例均以用户选定的 `frog-reference.png` 为准。`frog-v2.png` 是历史立绘，先前的 47 槽动作方案已弃用。身体裁图使用 `cutGrid(..., { pixelate: false })`，图像保留原分辨率，世界高度和脚底锚点按角色配置绘制。
- 新动作素材已逐格静态核对姿态、裁框、透明边界及锚点。最终237项规则测试通过；主游戏及同源审阅页已实测移动、跳跃、捧腹命中、直视玩家的护腹、指定侧躺、倒地和起身。具体观察范围见[验收记录](../design-qa.md)。
- 运行 `npm run build` 后，可从[奶蛙训练](http://127.0.0.1:4182/?practice=harbor&p1=frog&p2=banana)、[奶蛙高清审阅页](http://127.0.0.1:4182/frog-review.html)和[大肥鱼高清审阅页](http://127.0.0.1:4182/whale-review.html)检查显示结果。浏览器核对优先查看待机、移动、起落、格挡、命中反应和变身演出，再记录实际覆盖的操作。
