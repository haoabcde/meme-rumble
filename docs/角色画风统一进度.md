# 四角色画风统一

## 当前目标

保留队友角色的身份、服装、动作意图、朝向、表情和技能设计，实际重新生成高清卡通手绘素材。用户允许完全取消像素感；优先实际游戏中的脸、衣服和动作轮廓清晰度。仅改缩放和滤镜的方案已经撤回。

奶蛙体型按追加反馈修正：头更长、上半身更修长，同时保持明显圆鼓、向前挺出的大肚子。`frog-v2.png` 是最新腹部比例参考，旧矮圆动作和 `frog-basics-long-draft.png` 不能直接作为最终身体比例。

## 验收要求

- 新图保留每格原有姿势与表情；动作数量、格序和关键道具不丢失。不重新设计组合技、伤害或技能节奏。
- 真实PNG中的人物必须不透明、图外透明；不得只交生成工具预览。隔离红/蓝伪影、游离碎片和光晕，不能误删尾巴、发丝、泪水等真实内容。
- 新奶蛙不能在配准时再次压回原来的矮胖比例。落地脚底不漂，空中与倒地姿势保留原朝向。
- 高清大肥鱼图集可用2倍源像素；逻辑格仍为216，脚锚仍为(108,184)，世界尺寸和判定不变。构建按显式 `art.motionScale` 校验源格，不能把高清像素宽高当世界尺寸。
- 奶蛙身体不能继续经过旧 `cutGrid` 的三分之一像素化降采样；纯特效切图独立保留既有规则。
- 游戏中复查待机、走路、跳跃、攻击、格挡、受击、倒地起身及角色大招动作。通过规则回归后还必须观察实际动画，不以编译通过替代画面验收。
