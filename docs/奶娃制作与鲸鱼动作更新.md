## 设计判断

1. 第四段大击退会让第五脚接不上，因此第四段只轻推，第五脚用前移追击；双方朝向已验证。
2. 三次强击飞会导致第一波把人推出后两波，因此前两波留人、第三波兑现强击飞。
3. 全地图招式无距离成本，不能同时保留近身三波的完整伤害和连续释放频率；本版用较低伤害、较长前摇和2秒间隔。保留公共格挡、精准防反与闪避规则，未另加必中或破防。
4. 强化条采用战斗时间，命中停顿和双方大招演出均不消耗；不一边倒计时一边积气。视觉悬浮保留原来的地形/受击逻辑。

本轮完成所描述的普攻、技能1和大招，C技能保持预留；语音沿用此前延后统一制作的范围，没有新制“哈”与笑声音频。动作/数值为可试玩初稿，等待玩家评审，尚未定稿。
