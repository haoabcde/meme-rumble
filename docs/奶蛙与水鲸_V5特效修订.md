# 奶蛙与水鲸 V5 特效修订

本文件保留V5记录；当前以 [V6八向防反与强化结束过渡](奶蛙与水鲸_V6八向防反与退化过渡.md) 为准。

2026-11-22。以本次用户确认覆盖V4的纯白羽毛、技能羽毛简化及单根高光柱方案，战斗数值沿用既定规则。

## 大肥鱼左右普攻

原因是世界坐标先旋转、随后只翻转贴图，左侧的挥击角度没有随朝向镜像。现在所有定向拖尾均在向右局部坐标绘制，再整体翻转到角色朝向，涵盖弧光、水花和粒子。右侧原始设计保留，左侧三段逐帧对照右侧：第13、31、49帧分别为三段命中画面，左右均为45/90/135累计伤害。

## 奶蛙

- 七束圣光全部延伸至整个地图上方，在世界空间同步展开、轻摆、明暗变化、流光下落和收拢；跟随人物。移除游戏中原先截断的短扇形光束，不再以一根独立长柱代替整套光束。
- 太阳按原生图层等比显示，继续保持第一版高度和正圆；法环与羽毛图层保留。原库展示仍播放完整原始光柱，游戏使用关闭短光束的适配变体，再叠加长扇形光束。
- 普通、上＋技能一以及强化版本，均恢复库内羽毛爆散，释放后自然飘落；围绕施法者生成，不使用全地图伤害判定的地图中心作为羽毛发射点。
- 羽毛恢复此前黄白色阶和暖光，包括变身、技能爆散及少量移动拖尾。强化普攻和技能命中均恢复金白星芒，包含用户提供截图所示的星芒素材。
- 技能一仍使用完整冲击环，不恢复此前额外的日轮和三道天降圣光；无独立冷却、空中悬停、变身时停及各项倍率等不变。

120项自动测试通过，包含全部所选Pixel FX原生效果与光柱适配变体的完整前后层绘制，以及七束光均越过地图、独立运动、按时收束与黄白配色回归。
