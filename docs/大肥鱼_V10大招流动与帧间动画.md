# 大肥鱼 V10：大招流动与帧间动画

2026-11-23。本轮只细化大招演出与水潭阶段的表现，不改变战斗数值。未推送远程。

## 预览

http://127.0.0.1:4190/whale-review.html?scene=ult

默认播放水潭大招。支持正常/半速/四分之一速度、镜像、逐帧和时间轴；自由训练刷新后也使用同一套渲染。

## 修改

- 大招鲸鱼的姿态插值由每两个关键姿态间12个中间位置细化到24个，抬头和张嘴渐进展开，避免早早停在张嘴姿态。
- 用32段身体剖分做连续尾部主导的水波形变；头部振幅很小，尾部较明显。银白高光与身体使用同一条形变曲线，避免高光漂浮。
- 梁文峰身后的环鲸也采用更密的姿态与持续身体流动。龙卷风已定稿的鲸鱼渲染没有改动。
- 鱼群自身拖尾由10段细化到20段，持续弯曲并沿各自滞后位置游动。
- 水潭加入连续向外传播的椭圆波纹，水滴、鱼群与鲸鱼共用连续的表现时间。
- 正式游戏及大肥鱼预览传入两次逻辑更新之间的时间比例，按浏览器显示刷新采样，不再仅按整数逻辑帧跳位置。时停、命中停顿、暂停和逐帧查看仍保持精确静止。
- 在浏览器空闲时准备并缓存细化姿态，减少首次播放临时生成中间帧造成的停顿。

保持V8冰蓝、蓝灰体积和银白水纹配色；仍是0.6秒预警、12段各35伤害、总伤害420，米饭束缚1.2秒，演出全局时停。没有增加伤害判定帧或加快游戏逻辑。

## 验证

- 132项测试通过，含帧间路径连续性、尾部持续摆动、头部稳定及命中停顿/演出时水潭不推进。
- 浏览器检查了演出环鲸、大小水鲸、最后巨鲸、鱼群拖尾和水潭；无控制台错误或警告，实际仍命中12段420伤害。
- 验收页面可加 `&flowcheck=1`，点击“验收完整大招绘制耗时”，连续两遍各绘制300个逻辑帧。本机本次结果：首遍绘制耗时P95 14.9ms，复播2.9ms。此项为页面加载后完整渲染调用的CPU耗时，不等同于显示器实际帧率，也不代表所有机器性能。
- 后台页面会被浏览器限速，因此未将后台requestAnimationFrame频率视为游戏帧率。
