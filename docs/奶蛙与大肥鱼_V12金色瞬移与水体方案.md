2026-11-23。奶蛙改动接入正式本地游戏；大肥鱼本轮按用户要求先给优化效果图，候选材质仅在 `waterpreview=1` 预览开启，正式大招沿用V11。

## 奶蛙

- 上＋二技能脚下法阵统一整体放大、收缩，不再只压缩纵向造成前后摇摆；透视方向保持固定。常态仍较淡、无符文。
- 按本轮参考图重绘竖直符文法阵、三股金色流线透明像素双部件，强化瞬移时流线从实际起点弯向实际落点；前6帧完成连接，余光逐渐退去。
- 竖直法阵在人物身后，脚下法阵分前后半层；保留原地黄白羽毛与落点垂直光束。人物钻出遭碰撞体分离时，在显现帧同步记录实际落点，避免法阵中心与人物错开。
- 强化持按普通二技能仍为星图环绕，强化防御仍为符文牌；本轮新图只用于实际瞬移，不改变持按效果的用途。
- 成功绕背仍自动接一次强化技能一，实测3段140伤害；主动上＋二技能不自动接招。两方向已实看，未改变伤害、能量和判定规则。

## 大肥鱼：先看材质组合

已查本地完整 PixelFX 水系目录，实际只有两套独立水系效果，不虚构素材文件：

| 选用素材 | 本轮作用 |
| --- | --- |
| `water/whirlpool.js` | 向内流动的泡沫纹、细水流和碎亮点，投影到潭面，降低固体圆盘感 |
| `water/wave-crash.js` | 两侧翻开的卷浪、暗部水体、白色浪尖、受重力影响的水滴、白沫消散 |
| V11水膜与破水图集 | 顶起水膜、左右水幕和破水冠，与卷浪分前后层组合 |
| 已有水鲸/鱼群动作 | 保持现有连续变形、身体摆动与鱼群拖尾 |

候选潭面取消原来不透明径向渐变和整圈高沿，改为较透明水皮、细小起伏、流动泡沫与轻微不规则湿边。鲸鱼出水由鼓包→水幕撕开→左右卷浪→白沫和水滴组成，取消每次跃出的额外蓝色椭圆线圈。所有水体根部仍沿同一潭内曲线裁切，水鲸和鱼群离水后可以继续飞离。

保持冰蓝、蓝灰和银白同一色系；12段共420伤害、第12段击飞、0.6秒预警和演出时停不变。候选预览增加“水体近景 / 返回实战”按钮，在同一画布放大同一时刻的真实特效；暂停时缓存近景画面。
