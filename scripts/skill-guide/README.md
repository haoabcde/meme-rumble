# 两角色技能素材制作

本目录只处理大肥鱼和奶蛙的交付文案、视频、封面与素材预览，不修改游戏主 UI。技能卡数据位于 `catalog.mjs`，按角色定稿分支编写；主线差异另见交付总结。角色规则／素材换版时需同步更新基线提交，不将两套按法混在一个清单里。

1. 在仓库根目录运行 `npm run build`。
2. 运行 `node scripts/skill-guide/serve.mjs`。FFmpeg 默认使用当前机器的剪映版本；也可通过 `GUIDE_FFMPEG` 指定已安装的 FFmpeg。
3. 打开 `http://127.0.0.1:4195/record`，点击“录制全部技能”。正常速度实机运行并保存原声音总线；原始片和事件写入 `output/技能说明录制_20261126/`。
4. 打开 `http://127.0.0.1:4195/record?hq=1`，点击“导出全部高清技能”。同一脚本逐逻辑帧输出1920×1080 PNG，送入 H.264 QP16编码，显式120帧GOP与B帧；音轨复用上一步。中间文件写入 `output/技能说明高清_20261126/`。
5. 运行 `node scripts/skill-guide/finalize.mjs --hd`。核对两轮事件一致后复制高清视频、生成封面、文案、JSON和预览页。
6. 运行 `node scripts/skill-guide/verify.mjs`，逐段解码视频和音轨、核对哈希及关键命中结果。
7. 运行 `python scripts/skill-guide/package.py`，生成高清ZIP、哈希并验证清洁解压后的资源引用。

最终目录：`deliverables/大肥鱼与奶蛙角色交付_20261126/`。网页素材预览在 `http://127.0.0.1:4195/`。模糊的首版720p短片不作为交付，重新导出直接用定稿源，不能将其放大后冒充高清。

初始站位、能量、强化起始状态和随机种子属于演示场景。后续全部运行正式 `step` 与 `Renderer`；不直接改伤害、强制命中、移动敌人来制造连击或加速播放。强化结束卡单独展示到期转换，因此不用于证明完整15秒时长。
