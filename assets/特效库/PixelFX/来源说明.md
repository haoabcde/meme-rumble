# Pixel FX 选用模块

来自本地完整 Pixel FX v0.3.1，MIT（Patch / Hugo Duprez，2026）。保留相邻许可证及每个模块的 Sprite Fusion 来源注释。这里只携带本角色实际选用模块及完整依赖图，完整素材库仍位于工作区 pixelfx 目录。

- impacts/blunt-hit：拳脚命中
- arcane/mana-burst：哈、捧腹、全图冲击
- melee/uppercut：飞踢的弧形气流
- holy/holy-pillar：变身圣光
- holy/halo：强化光环
- holy/feather-burst：变身羽毛
- weather/god-rays：指尖演出天光

这些特效只负责画面，既不治疗也不修改判定。原色展示与金白适配色都在奶娃工作台。

本轮新增：
- melee/thrust：普通拳锋气流、强化定向光击（隐藏库内演示人物/武器，只取效果）。
- impacts/hit-spark：强化命中星芒。
- holy/smite：强化飞踢光击、强化捧腹圣光落点。
- holy/sunburst：强化哈与捧腹的日轮放射。

圣光柱和羽毛使用库内完整时长，演出结束后在战场播放。新增模块保留全部原始来源与版权注释。
