# 音频联调测试信号

这四个 WAV 由 Python 标准库合成，使用 22,050 Hz、16 位的单声道 PCM。语音轨也使用电子脉冲，素材仅供音频联调。

| 文件 | 信号 | 时长 | 触发条件 |
| --- | --- | --- | --- |
| `probe-start.wav` | 960 Hz 短音 | 75 毫秒 | U 动作第 0 帧，走音效轨 |
| `probe-interrupt.wav` | 420 Hz，7 个脉冲 | 1.4 秒 | U 动作第 12 帧，走语音轨，动作中断时停止 |
| `probe-continue.wav` | 660 Hz，7 个脉冲 | 1.4 秒 | I 动作第 0 帧，走语音轨，动作中断后继续 |
| `probe-impact.wav` | 220 Hz 和 330 Hz 双音 | 155 毫秒 | U 动作命中或被格挡时，走音效轨 |

构建后打开 `dist/audio-demo.html`，先点击画布解锁音频。在默认静止陪练、1× 速度下，按 U 会依次听到起手短音、约 0.2 秒后的低音脉冲和约 0.6 秒时的双音命中。按 I 会立即听到较高的脉冲。等动作结束再开始下一次测试。

测试打断时，打开「训练设置」，将陪练改为「重复直拳」，速度改为 0.5×。按 R 复位并紧接着按 U 或 I。陪练第一拳会在约 1 秒后命中，按 H 可显示受击状态。U 的低音脉冲应在受击时停下，I 的高音脉冲应继续播完。

分别将音效和角色语音设为 0，可以用 U 检查另一轨是否仍有声音。总音量设为 0 时，两轨一起静音。
