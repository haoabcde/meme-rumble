## 生成提示词约束

共同要求：`identity-preserving style-transfer`。以原角色图锁定身份、外形、配色、站姿和表情，统一成清晰卡通手绘：干净略有手感的深色轮廓、简洁明暗、哑光色块和少量细微笔触。不采用模糊处理、粗像素块、外发光或矢量高光。真实透明PNG，人物本身不透明，完整头发、脚和道具可见，无地面阴影、文字或额外物体。

大肥鱼先以原奶蛙图的手绘质感生成；另外三位共同参考大肥鱼新图，保持同一套线条与上色。每个角色单独调用ImageGen，局部错误单独修订。奶蛙首次透明导出错误并带棕色光晕，已弃用；当前图已检查实际保存PNG的主体与透明度。

后续用户允许完全取消像素感，所有动作重绘采用清晰手绘。奶蛙追加约束是“头更长、上半身修长，但肚子更大更鼓”，姿态不能被复装步骤压回旧矮胖比例。
