# 两角色技能素材 UI 接入说明

此包只交付大肥鱼和奶蛙的说明文案、实机短片、封面及数据，不改游戏主界面。队长可把两个角色的数据合入四角色“操作说明”。`index.html` 是素材核对页，解压后双击可看；也可从本地服务打开。

## 文件

| 文件 | 用途 |
| --- | --- |
| 给队长的角色设计与接入总结.md | 已确认设计、与主线差异、合入顺序及验收边界 |
| 技能清单.json | 两角色技能卡的唯一数据入口，UTF-8，包含默认键位与逻辑命令 |
| 玩家技能说明.md | 面向玩家的文字，可复制进操作说明 |
| videos/角色名/*.mp4 | 各技能独立短片，H.264、AAC、1920×1080、每秒60个源逻辑帧，正常速度 |
| posters/角色名/*.jpg | 与短片一一对应的封面 |
| 录制与文件校验.json | 实际录制帧率、战斗事件、视频 SHA-256 与来源版本 |
| index.html | 本地素材预览，选择角色／技能后看按法、说明、视频 |

`videos/` 和 `posters/` 必须与 JSON／预览页保持相对位置。所有文件一起复制，或在接入时统一加资源路径前缀；不要只复制 HTML。

## 数据约定

顶层 `characters` 仅有 `whale` 和 `frog`。每个角色的 `skills` 记录一张技能卡：

| 字段 | 含义 |
| --- | --- |
| id | 稳定技能卡 ID，如 whale.rice、frog.power-counter；不随显示名或改键变化 |
| name、category、description、tips | 技能名、分类、效果及必要限制，可直接用于玩家 UI |
| p1、p2 | 本素材对应版本的默认按法，供核对／后备显示；不覆盖玩家的重绑设置 |
| command | 逻辑输入：key 为 A／B／C／ULT／dash／down；direction、posture、form、hold、repeat、trigger、sequence、condition 表示方向、地空、强化、持按、连按和触发条件 |
| actionIds、actions | 角色定稿分支的动作 ID 及对应槽位／阶段；动作值用于版本核对，不是另一份战斗配置 |
| video、poster | 相对于素材根目录的资源路径 |
| cost | 有消耗时给玩家看的文字；未写表示该技能不消耗大招气，不代表没有状态／收招约束 |
| recording | 编码与逐帧导出规格。encodedFps 是文件帧率，sourceLogicalFps 为源场景逻辑帧率；sourceFrames 记录导出帧数 |

P1 当前逻辑映射是 A→J、B→U、C→I、ULT→O、jump→K、dash→L。P2 对应数字小键盘 1、4、5、6、2、3；玩家说明统一显示数字小键盘按键。`direction:up` 应映射到方向 W／↑，不是跳跃键。

`form:powered` 代表该卡讲强化形态，不是要求玩家另外按一个“强化键”。`trigger` 描述自动发生的条件；例如铁盆是先按住防御，再由正面受击触发。连招提示卡 `sequence` 描述操作先后，不是同帧同时按下。

## 推荐挂接方式

1. 玩家进入“操作说明”，选角色后列出普通、方向变招、强化和连招提示。
2. 每张卡只展示名称、实际按法、效果、必要限制及一个视频。动作帧数、版本号与文件校验保留给维护者。
3. 把 `command` 交给当前绑定生成可见按法。若最终将大肥鱼旋风改到方向＋U，先明确技能 ID 映射，再同步改 command；不能保留本包旧 I 文案。新增主线招式另列，不把未拍的招式伪装成本包视频。
4. 视频默认静音、手动播放，允许开启声音、暂停、重播与全屏。切角色／技能或关闭说明时暂停旧视频。使用 `playsinline`、`preload="metadata"`，只加载被选中的视频。
5. 队长的四角色界面保留香蕉猫、咕咕嘎嘎原有数据；本包追加两个角色即可。不要将此二角色预览页直接覆盖最终 UI。

示例（资源前缀由项目部署决定）：

```js
const card = guide.characters.find(c => c.id === selectedCharacter).skills[selectedSkill];
video.pause();
video.src = resourceBase + card.video;
video.poster = resourceBase + card.poster;
video.muted = true;
video.load();
title.textContent = card.name;
description.textContent = card.description;
// 正式按键标签应由 card.command 与游戏当前 bindings 生成。
```

## 演示边界

短片来自角色分支 `4af7d13` 的正式角色包、战斗逻辑和渲染器。统一使用余晖货港，1×速度；演示初始化提供固定站位和气量，强化技能卡从强化状态开始，强化结束卡从即将到期的状态开始。偷吃卡使用一个实际触发偷吃的固定随机种子，不是把概率改成必定。

画面复用定稿演示源，逐逻辑帧绘制并以无损PNG送进编码器，单次 H.264 QP16 编码，无低码率限制。视野采用较近的 960×540 逻辑画幅，以2倍背板直接绘制到1920×1080；矢量特效直接按高清尺寸绘制，像素素材关闭平滑，不放大已经压糊的视频。每秒60帧，命中停顿仍保留，不生成虚构中间姿势。高清导出与原实机片的战斗事件逐条核对一致。

音轨复用同一输入脚本的原实机声音总线录制，不使用麦克风或系统混音。核对视频只放大展示取景，不改变技能判定、持续时间或正常播放速度。大范围特效可能冲出画面，与角色定稿效果一致。

这些视频说明角色定稿效果，不声称主线的改键、新招与计时 UI 已经与原稿统一。请先阅读队长总结中的差异表，再把素材接进最终版本。
