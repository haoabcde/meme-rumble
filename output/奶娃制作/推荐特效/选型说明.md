# 奶娃特效选型

工作台可直接播放每个特效并在原始配色/金白色之间切换。相邻GIF为库内原始配色、无占位人物的动态导出；RGB帧仅用于编码，未提交。

| 用途 | 选用特效 | 适配 |
|---|---|---|
| 左右拳、踢腿命中 | impacts/blunt-hit | 短促爆点、少量碎屑 |
| 哈、捧腹、全图冲击 | arcane/mana-burst | 金白配色，压缩聚能段，连续三次独立释放；全图版额外扩散金环 |
| 最后一脚追击 | melee/uppercut | 旋转弧光方向，伴随前移 |
| 神了！变身 | holy/holy-pillar | 圣光汇聚 |
| 天使强化 | holy/halo | 与人物已有光环对齐，添加流光 |
| 变身余韵 | holy/feather-burst | 羽毛爆散与沉降 |
| 云层演出 | weather/god-rays | 像素天光和浮尘 |

虽然库中存在治疗类特效，本版不使用治疗逻辑。所有选用模块均为MIT，保留原作者与Sprite Fusion来源说明。
