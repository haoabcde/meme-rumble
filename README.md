# Meme 乱斗 · 抽象之王

用桌面浏览器打开单文件即可离线游玩，程序、界面和地图都已内嵌。[下载游戏](https://github.com/haoabcde/meme-rumble/releases/latest/download/meme-rumble.html)

从源码运行时，在仓库目录执行 `npm ci` 和 `npm run build`，再打开 `dist/index.html`。

## 进入对战

1. 从标题页进入本地双人、人机对战或自由训练。
2. 双方各选一位并确认。四位可选角色是 DeepSeek 鲸鱼娘、奶蛙、香蕉猫、姑姑嘎嘎。双方可以使用同一角色。
3. 选地图。默认场地是余晖货港。点「登台路线」可查看双方从开局点到高台的走法。标准局为每回合 60 秒、先赢两回合，可在选图页调整。
4. VS 开场会显示阵容、场地和规则。结算页逐回合记录结果，支持保留规则与阵容再战，也可以换人、换图或返回模式。

单人验证地图时可直接选**自由训练**。屏幕左下会随实际落脚更新平台名称和已到达的最高层。陪练可静止、防御或跟随，训练支持半速。暂停后可前进一帧，按 R 可以重置。

| 地图 | 可走宽度 | 场景和路线 |
|---|---:|---|
| 宿舍楼顶 | 2.9 屏 | 花坛和温室可以接上两侧阳台，连廊能长距离追击，机房屋顶在桥中央。 |
| 夜训球场 | 3.0 屏 | 两翼半场用于拉扯，外侧长椅和中央替补席都能跳上看台，再跃上计分牌检修台。 |
| 余晖货港 | 3.3 屏 | 地面贯通两个船坞。中路三段桥可以连续横跳。两翼有四层，检修廊内沿可以上下横移吊盘。 |
| 星电站 | 3.0 屏 | 两塔各有高台，从中层电缆桥横跳或走地面都能换边。 |

双方从开局点用一次普通跳跃就能到各自路线的首个平台。货港最高的西吊架检修廊离地 529 游戏单位，另外三张场地的最高台约为 400。货港通往检修廊的相邻两层相差 130–137 单位，普通跳跃的峰值为 153。对战中计时器下方的条带显示双方在场地中的位置和当前镜头范围。

第一次玩货港时，P1 开局按住 A 再按 K，可落到西侧青色货柜。沿柜顶往左一小段，再跳上黄色栈桥。从桥的右端向右跳到青色转运桥，再从转运桥右端跳向东侧栈桥。横移吊盘靠近时可以跳上去，松开方向键就会随它移动。在西侧栈桥上方按 S＋K，可以从吊盘落回栈桥。自由训练里将陪练切到「跟随」，它也会沿平台追上来。

## 公共按键

| 操作 | P1 | P2 |
|---|---|---|
| 左右移动 | A / D | ← / → |
| 防御 | S | ↓ |
| 跳跃 / 二段跳 | K | 右 Shift 或小键盘 2 |
| 逐层下穿 | S + K | ↓ + 右 Shift |
| 地面 / 空中冲刺 | L | Enter 或小键盘 3 |
| 普攻 / 空中攻击 | J | 逗号或小键盘 1 |
| 地面挑空 | W + J | ↑ + 逗号 |
| 预留专属槽 | U / I | 句号 / 斜杠 |

第一拳打中后再按攻击，可接第二段和第三段。第三段击倒对手，对手落地后从倒地过渡到起身，起身结束恢复操作。前两段也能接挑空。以 P1 为例，按 J 命中、W + J 挑空、K 起跳、J 空中追击。打空或被防住时要等收招。每次离地可在二段跳和空中冲刺之间选一次，落地恢复。

从台面下方起跳，在下降经过台沿时落脚，空中可以左右调整。按住下方向再跳跃会从脚下的平台向下掉一层。Esc 暂停，H 显示判定框与台沿。在自由训练中，H 还会显示双方所处的动作阶段、剩余帧数和最近四次按键。选角的方向键和确认键可在「设置」内修改，操作说明会一起更新。同键冲突会提示。全屏受容器限制时，「全屏」会切换到窗口内放大。

## 接入正式技能

四位角色共用普攻、挑空、跳追和空中冲刺规则。[roster.ts](src/content/roster.ts) 的 `signatureMoves` 保留角色专属动作入口，当前每位的 B/C 槽都是空的。方向和键位、地面/空中限制、起手/有效/收招帧、攻击框、伤害及硬直都由动作数据填写。`cancelOnHit` 可引用动作 ID、按键槽，或用 `jump` 开放地面命中后的跳追。只从连击接入的动作设置 `linkOnly`。帧数基于固定 60 Hz，判定框以角色脚底为原点，按朝右填写，内核负责镜像。

技能的射程、影响高度与位移按世界坐标设计。场地左右边界用 `arena.left` 和 `arena.right`，地面高度用 `arena.floor`。1280×720 是镜头画布尺寸，镜头平移和缩放独立于战斗判定。

## 地图、美术与运行

- [场地数据](src/content/arenas.ts) 定义出生点、可走边界和登台路线。[货港布局](src/content/harbor.ts) 把货柜、步桥、渡船、值班室与吊盘的落脚线放进同一份数据。选图预览、实战与训练都使用这些坐标。
- [地图资产](assets/arenas) 包括宽场画稿与货港的分层景物。货港的海面跟随镜头产生视差，码头地面和可站台沿对齐世界坐标。[吊盘轨迹](src/core/terrain.ts) 由固定帧推进。[资产制作记录](assets/README.md)
- [角色资产](assets/fighters) 中的 `*-motion.webp` 包含跑动、起手、不同攻击、格挡、收招与受击姿势。姿势按战斗状态和动作帧切换。 [动作图集规格](assets/README.md#公共动作图集)
- TypeScript 固定 60 Hz 战斗内核、Canvas 2D 渲染、Web Audio。默认使用同屏跟随，设置里可以切换近身特写。 [镜头计算](src/web/camera.ts)

开发需要 Node.js 20 或更新版本。

```sh
npm ci
npm run build
npm test
```

构建生成 `dist/index.html`，内嵌十五张 WebP、样式与脚本。 [详细验收记录](design-qa.md)
