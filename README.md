# Meme 乱斗 · 抽象之王

克隆仓库后运行 `npm ci` 和 `npm run build`，再用桌面浏览器打开 `dist/index.html`。HTML 已内嵌程序、界面、角色和地图，打开即可离线游玩。

## 进入对战

1. 从标题页进入本地双人、人机对战或自由训练。
2. 双方各选一位并确认。四位可选角色是 DeepSeek 鲸鱼娘、奶蛙、香蕉猫、姑姑嘎嘎。双方可以使用同一角色。
3. 选地图。预览显示全场和可走宽度，点「登台路线」查看一条从地面到顶层的路线。标准局为每回合 60 秒、先赢两回合，可在选图页调整。
4. VS 开场会显示阵容、场地和规则。结算页逐回合记录结果，支持保留规则与阵容再战，也可以换人、换图或返回模式。

单人验证地图时可直接选**自由训练**。屏幕左下会随实际落脚更新平台名称和已到达的最高层。陪练可静止、防御或跟随，训练支持半速。暂停后可前进一帧，按 R 可以重置。

| 地图 | 可走宽度 | 场景和路线 |
|---|---:|---|
| 宿舍楼顶 | 2.9 屏 | 花坛和温室可以接上两侧阳台，连廊能长距离追击，机房屋顶在桥中央。 |
| 夜训球场 | 3.0 屏 | 两翼半场用于拉扯，外侧长椅和中央替补席都能跳上看台，再跃上计分牌检修台。 |
| 余晖货港 | 3.3 屏 | 地面全线贯通，卸货台、货柜、错位栈桥和悬吊货盘形成高低路线。 |
| 星电站 | 3.0 屏 | 两塔各有高台，从中层电缆桥横跳或走地面都能换边。 |

三层路线的最高台离地约 400 游戏单位。常用登台路线每级相差 129–136 单位，公共跳跃的峰值为 153。对战中计时器下方的条带显示双方在场地中的位置和当前镜头范围。

## 公共按键

| 操作 | P1 | P2 |
|---|---|---|
| 左右移动 | A / D | ← / → |
| 防御 | S | ↓ |
| 跳跃 | K | 右 Shift 或小键盘 2 |
| 逐层下穿 | S + K | ↓ + 右 Shift |
| 冲刺 | L | Enter 或小键盘 3 |
| 基础攻击 | J | 逗号或小键盘 1 |
| 预留专属槽 | U / I | 句号 / 斜杠 |

从台面下方起跳，在下降经过台沿时落脚，空中可以左右调整。按住下方向再跳跃会从脚下的平台向下掉一层。Esc 暂停，H 显示判定框与台沿。选角的方向键和确认键可在「设置」内修改，操作说明会一起更新。同键冲突会提示。全屏受容器限制时，「全屏」会切换到窗口内放大。

## 接入正式技能

四位角色使用同一套公开的测试生命值、移动参数和基础攻击。[roster.ts](src/content/roster.ts) 的 `signatureMoves` 保留角色专属动作入口，当前每位的专属槽都是空的。团队确认后，在对应角色填入 B/C 槽的动作定义。方向和键位、地面/空中限制、起动/有效/收招帧、攻击框、伤害及硬直都由数据描述。帧数基于固定 60 Hz，判定框以角色脚底为原点，按朝右填写，内核负责镜像。

技能的射程、影响高度与位移按世界坐标设计。场地左右边界用 `arena.left` 和 `arena.right`，地面高度用 `arena.floor`。1280×720 是镜头画布尺寸，镜头平移和缩放独立于战斗判定。

## 地图、美术与运行

- [场地数据](src/content/arenas.ts) 以原创画稿的台沿像素建立碰撞。选图预览和实战按同一组高度坐标绘制，训练显示实际站立的平台。
- [地图资产](assets/arenas) 中的 `*-wide.webp` 是宽场版画稿。台沿端头的细色标标明可站边界。 [资产制作记录](assets/README.md)
- TypeScript 固定 60 Hz 战斗内核、Canvas 2D 渲染、Web Audio。默认使用同屏跟随，设置里可以切换近身特写。 [镜头计算](src/web/camera.ts)

开发需要 Node.js 20 或更新版本。

```sh
npm ci
npm run build
npm test
```

构建生成 `dist/index.html`。本轮通过本机 HTTP 预览验证了最终画面、交互与按键。构建检查确认九张 WebP、样式与脚本均在单文件内嵌，应用内浏览器的 `file:` 入口仍由浏览器限制。 [详细验收记录](design-qa.md)
