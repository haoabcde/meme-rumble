# Meme 乱斗 · 抽象之王

克隆仓库后运行 `npm ci` 和 `npm run build`，再用桌面浏览器打开 `dist/index.html`。HTML 已内嵌程序、界面、角色和地图，打开即可离线游玩。

## 进入对战

1. 从标题页进入本地双人、人机对战或自由训练。
2. 双方各选一位并确认。四位可选角色是 DeepSeek 鲸鱼娘、奶蛙、香蕉猫、姑姑嘎嘎。双方可以使用同一角色。
3. 选地图。预览显示全场和可走宽度，点「登台路线」查看双方从出生点到顶层的路线。标准局为每回合 60 秒、先赢两回合，可在选图页调整。
4. VS 开场会显示阵容、场地和规则。结算页逐回合记录结果，支持保留规则与阵容再战，也可以换人、换图或返回模式。

单人验证地图时可直接选**自由训练**。屏幕左下会随实际落脚更新平台名称和已到达的最高层。陪练可静止、防御或跟随，训练支持半速。暂停后可前进一帧，按 R 可以重置。

| 地图 | 可走宽度 | 场景和路线 |
|---|---:|---|
| 宿舍楼顶 | 3.1 屏 | 从两翼花房与种植台登上连廊，经机房或晾晒台抵达水塔。 |
| 夜训球场 | 3.4 屏 | 开阔的中圈适合地面对打。两翼由替补棚、看台和转播席通往实时计分牌。 |
| 余晖货港 | 3.3 屏 | 三段栈桥可以横跳换边，横移吊盘在两座龙门吊检修廊之间往返。 |
| 星电站 | 3.3 屏 | 双塔各有登顶路线，中央升降机可直达塔冠附近。 |

四张地图都有地面和四层高台，最高台离地 527–529 游戏单位。公共跳跃的峰值为 153，固定路线可逐层单跳。计时器下方的条带显示双方在场地中的位置和当前镜头范围。

## 公共按键

| 操作 | P1 | P2 |
|---|---|---|
| 左右移动 | A / D | ← / → |
| 防御 | S | ↓ |
| 跳跃 | K | 右 Shift 或小键盘 2 |
| 逐层下穿 | S + K | ↓ + 右 Shift |
| 冲刺 | L | Enter 或小键盘 3 |
| 基础攻击 | J | 逗号或小键盘 1 |
| 技能槽 1（B，角色专属技能） | U | 句号或小键盘 4 |
| 技能槽 2（C，角色专属技能） | I | 斜杠或小键盘 5 |
| 大招（角色专属） | O | 单引号或小键盘 6 |

从台面下方起跳，在下降经过台沿时落脚，空中可以左右调整。按住下方向再跳跃会从脚下的平台向下掉一层。Esc 暂停，H 显示判定框与台沿。选角的方向键和确认键可在「设置」内修改，操作说明会一起更新。同键冲突会提示。全屏受容器限制时，「全屏」会切换到窗口内放大。

## 姑姑嘎嘎的五段普攻

| 招式 | P1 默认键 | 起动 / 有效 / 收招 | 基础伤害 |
|---|---|---|---|
| 第一段 · 前鳍直击 | J | 5 / 2 / 14 | 36 |
| 第二段 · 转身反拍 | 连按 J | 6 / 3 / 14 | 41 |
| 第三段 · 电线杆横扫 | 连按 J | 11 / 4 / 18 | 50 |
| 第四段 · 电线杆反扫 | 连按 J | 12 / 4 / 19 | 44 |
| 第五段 · 电线杆挑飞 | 连按 J | 15 / 5 / 22 | 114 |
| 突进挑飞 | W + J | 16 / 3 / 16 | 95 |
| 肚皮滑撞 | S + J | 11 / 27 / 21 | 130 |
| 空中掷杆 | K 跳起后按 J | 8 / 1 / 20 | 110 |

地面连续按五次 J 就会排入五段动作。可以在蓄力、命中停顿或收招窗口继续按，打空和被防御时也会接续。第三、四段横向挥动电线杆，末段从下往上将命中的对手挑飞。三段挥杆都有更长的蓄力和收势，也会带起地面灰尘和风声。

在地面按住上或下再按普攻，分别发动突进挑飞和肚皮滑撞。挑飞前突进 240 世界单位，滑撞空放移动 784 世界单位。默认 P2 用 ↑ 或 ↓ 搭配逗号。

跳起后按普攻会朝面向斜下方掷出电线杆。飞杆穿过所有平台，能命中一次，在最底层地面炸开尘土和碎块，留下一道短暂裂纹。表中空中掷杆的有效帧是离手时刻，之后飞杆独立前进。

双方每回合从空气条开始，最多 3 格。普攻、蓝弹、榴弹爆炸实际伤到对手时，攻击方加 0.12 格，挨打方加 0.18 格。普通技能消耗 1 格，最终技能消耗 3 格，气不足时无法发动。

地面按 I 向前上抛蓝色箱，展开后是双铳口铳械塔。跳起后按 I 斜下丢橙色箱，箱子穿过平台，在最底层展开成单圆炮口的榴弹炮。两招各消耗 1 格气，箱子直接命中基础伤害 55。每种炮台全场各一座，箱子着地时炸毁同类型旧炮台，20 帧后完成施工并产生气浪，击中时造成 45 基础伤害并把对手向外震开。炮台承受两次攻击，从着地起最多存在 30 秒。

建成后每 2 秒射击一次。铳械塔射出基础伤害 32 的蓝色直线弹。榴弹炮射出有限射程的圆形榴弹，榴弹沿抛物线飞行，落在第一个台面或地面时爆炸。爆心基础伤害为 90，离爆心越远伤害越低。

咕咕嘎嘎在地面按 O 消耗 3 格气召唤帝江号。发动时根据对手的位置锁定俯冲路线和一楼落点，时停 48 帧播放人物和终端操作特写。帝江号随后斜向下俯冲 36 帧（0.6 秒），沿途撞到高台或空中的对手会带着对手穿过平台，在一楼造成伤害。直接命中一楼的对手会击退并挑飞。基础伤害 320，无视格挡。

姑姑嘎嘎的步态由上身、双腿和脚蹼分别绘制。前进稍前倾，后退面朝对手并缩短步幅。步态随实际行走距离推进，转向或松键时会过渡到新的姿态。

命中火花与音效随轻击、重击、挑飞和滑撞变化，格挡有冷色火花。命中星按出手方着色：香蕉猫橙金，姑姑嘎嘎紫色，炮台与榴弹沿用各自的颜色。姑姑嘎嘎受击时按轻击、重击和空中反应选择不同关键帧，命中停顿保留冲击姿势，落地有短暂屈膝缓冲。

[咕咕嘎嘎动作模组](src/content/fighters/gaga.ts) 记录每段的接续窗口、起动、有效、收招、攻击框、伤害和硬直。帧数基于固定 60 Hz，判定框以角色脚底为原点，按朝右填写，内核负责镜像。

技能的射程、影响高度与位移按世界坐标设计。场地左右边界用 `arena.left` 和 `arena.right`，地面高度用 `arena.floor`。1280×720 是镜头画布尺寸，镜头平移和缩放独立于战斗判定。

## 香蕉猫 · 眼泪值

香蕉猫每回合从 60 点眼泪值开始，上限 100 点，显示在血条下方。每次普攻实际命中回 8 点，受到敌人攻击并掉血回 5 点。另有独立气条，每回合从空条起步，上限 3 格。普攻、U 高压眼泪和 W + U 哭哭升龙实际命中回 0.12 格，受击掉血回 0.18 格。

| 操作 | P1 | P2 | 效果 |
|---|---|---|---|
| 高压眼泪 | U | 句号 | 起手消耗 20 点，长按额外每秒消耗 10 点。喷射时可慢移，命中减速。 |
| 哭泣回泪 | 按住 I | 按住斜杠 | 每秒恢复 20 点。 |
| 哭哭升龙 | W + U | ↑ + 句号 | 消耗 35 点，向上喷泪并挑飞对手。 |
| 空中水球 | 跳起后按 J | 跳起后按逗号 | 消耗 10 点。水球碰到敌人就爆炸，打空时穿过上层平台，在一楼爆炸。 |
| 泪海滔天 | 地面 O | 地面单引号或小键盘 6 | 消耗 3 格气。特写结束后向前卷起大片海浪，击退并挑飞敌人。 |

在自由训练中展开「训练设置」，点「充满三格能量」即可试招。眼泪值在血条下方，三格气槽在画面底部。

地面普攻保留左右爪、头撞、嚎啕震开四连击，以及上 + 普攻的蕉尖挑飞和下 + 普攻的泪水滑铲。改键后，操作说明和训练提示会同步更新。

## 角色接口

香蕉猫和姑姑嘎嘎分别通过角色包登记普攻、专属技能、大招和美术。大招走独立的 \`ULT\` 槽，消耗使用 0–300 点单位。逐帧判定、独立实体和命中反馈可在联调页试验。 [角色接口](docs/character-handoff.md)

## 地图、美术与运行

- 选图预览、建筑台沿和落脚判定共用场地数据。货港吊盘与星电站升降机随可推进的战斗帧移动。 [场地数据](src/content/arenas.ts) · [移动平台轨迹](src/core/terrain.ts)
- 远景和建筑分层绘制，球场计分牌随对局更新。 [资产制作记录](assets/README.md)
- TypeScript 固定 60 Hz 战斗内核、Canvas 2D 渲染、Web Audio。默认使用同屏跟随，设置里可以切换近身特写。 [镜头计算](src/web/camera.ts)

开发需要 Node.js 20 或更新版本。

```sh
npm ci
npm run build
npm test
```

构建生成 `dist/index.html`。既有界面、地图与单文件内嵌的 HTTP 预览验收见 [历史验收记录](design-qa.md)，应用内浏览器的 `file:` 入口仍由浏览器限制。香蕉猫的机制与参数见 [角色设计](香蕉猫角色设计.md)。
